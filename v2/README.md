# 钩影 · 云阙坠墨

2D 横版钩索飞荡生存闯关游戏，国潮扁平美术风格。所有画面都用 Canvas 矢量实时绘制，音乐用 WebAudio 合成，无需任何外部资源。

- 玩法详解见 [GAMEPLAY.md](GAMEPLAY.md)
- 鼠标左键 / 右键 = 左手 / 右手钩索（按住掷出并挂住，松开放手；两手都松开会坠落）
- 自动攻击；收集灵气升级学技能（5 槽，Lv10 MAX）
- 击败精英掉落法宝（6 槽），用金币强化法宝（Lv4 MAX），Lv2 时三选一锁定强化路线
- 擦身 / 击杀积攒剑意，空格释放「万剑归宗」；P 暂停，M 静音
- 墨灾六将依次登场：赤焰金乌 → 千机傀师 → 墨魇饕餮 → 刀螂将军 → 金蜂娘娘 → 皮影判官

直接用浏览器打开 `index.html` 即可游玩。
