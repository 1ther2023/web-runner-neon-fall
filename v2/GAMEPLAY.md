# 《钩影 · 云阙坠墨》玩法说明

**一句话概括：** 用双手钩索在空中楼阁之间飞荡的横版生存闯关游戏。攻击全自动，玩家只负责移动和选择成长路线。整体属于 “Roguelite 割草 + 物理摆荡平台” 的混合品类。

---

## 1. 核心操作：双手钩索

| 输入 | 效果 |
|---|---|
| 按住鼠标左键 / 右键 | 左手 / 右手向鼠标方向掷出钩索，钩中屋檐或灯舫就挂住 |
| 松开鼠标 | 该手放开钩索 |
| 空格 | 剑意满时释放大招「万剑归宗」 |
| P / Esc，M | 暂停；静音 |

- **单手挂住 = 摆荡**：绕挂点做钟摆运动，挂着时会持续获得向前的推力。
- **双手挂住 = 悬停**：两根钩索同时拉住，身体稳定，适合躲弹幕。
- **两手都松开 = 飞出去**：放手瞬间保留速度，还会额外加速并空翻。不过这时你在自由下落，**坠出画面底部会直接死亡**。
- 技巧核心是 **“左右手交替”**：一只手还挂着，另一只手先钩住下一个点，再放开前一只手，这样就能一直向前、永不落地。

## 2. 生存压力：三面夹击

1. **左侧墨潮**：以不断加快的速度向右推进，碰到会持续掉血，逼着玩家一直前进。
2. **底部墨海**：掉下去就死。
3. **敌人与弹幕**：从右侧和上方涌来，是典型的弹幕射击（STG）压力。

镜头始终锁定玩家在画面正中央，墨潮和墨海固定在世界里，能直接看出离危险有多远。

## 3. 战斗：全自动攻击

- 玩家不需要瞄准或开火，所有技能都会自动索敌并释放。
- **擦弹**：敌弹贴身擦过而不命中，会积攒剑意，并可能触发装备效果。
- **弹幕对消**：玩家的飞镖可以抵消敌人的子弹。
- **大招「万剑归宗」**：剑意满后按空格释放。会清空全屏子弹并转化成金币，对屏幕内敌人造成巨额伤害，持续几秒内无敌、攻速翻倍。

## 4. 成长系统（局内 Roguelite）

| 系统 | 来源 | 规则 |
|---|---|---|
| **技能**（5 槽，Lv10 满级） | 击杀掉落「灵气」→ 升级 → 三选一 | 10 种技能：飞镖、绕身飞剑、纸鹤追魂、铁扇横扫、掌心雷、机关木鸢、霹雳火球、贯日剑气、天女散花、御风冲击 |
| **法宝**（6 槽，Lv4 满级） | 击败 **精英** 掉宝箱 → 三选一 | 8 种法宝，提供生命、减伤、暴击、回血、冷却、伤害等 |
| **法宝强化** | 金币攒够自动弹出 | 法宝从 Lv1 升到 Lv2 时，要从 **A / B / C 三条路线** 中选一条并锁定，Lv3、Lv4 沿路线继续加强 |

每一局的技能组合与路线选择都不同，这是 Roguelite 的重玩性来源。

## 5. 敌人与 BOSS

- **8 种普通敌人**，行为各不相同：
  - **纸鸢哨**：直射。
  - **墨甲卫**：三连弩。
  - **墨魉**：自爆冲锋。
  - **铜镜妖**：旋转弹幕。
  - **机关楼船**：环形弹 + 散射。
  - **雷火灯**：靠近会引爆。
  - **墨蝠**：蓄力后突刺。
  - **机关鹤**：先红线瞄准，再打出高速狙击弹。
- **精英**：体型更大、血更厚，会额外放环形弹。击败必掉法宝。
- **墨灾六将**：大约每 2 分钟一位，每位有 4 到 5 种专属弹幕招式，血量低于一半后进入狂暴状态。
  1. 赤焰金乌
  2. 千机傀师
  3. 墨魇饕餮
  4. 刀螂将军
  5. 金蜂娘娘
  6. 皮影判官

  六将全部击败后，会以强化形态轮回登场。

## 6. 难度曲线

| 时间 | 阶段 |
|---|---|
| 0 – 2 分钟 | 热身：敌人稀疏，熟悉摆荡 |
| 2 – 6 分钟 | BOSS 依次压上，敌人种类和密度提升 |
| 6 分钟以后 | **墨劫降临**：敌人血量、伤害、刷新速度按指数增长，比拼能撑多久 |

一局的目标时长约 6–8 分钟。

## 7. 结算

结算按存活时间、前进距离、击败的 BOSS 数、击杀数、金币、等级、最大连斩、擦弹次数计分，给出 S / A / B / C / D 评级，并在本地记录最高分。
