# 蛛影疾驰 WEB RUNNER · 霓虹坠城

3D 横版蛛丝飞荡生存闯关游戏（Three.js 程序化建模 + 辉光后期 + WebAudio 合成音乐）。

像素版保留在 `pixel-v1` 标签。

- 鼠标左键 / 右键 = 左手 / 右手蛛丝（按住发射并抓住，松开放手；两手都松开会坠落）
- 自动攻击；收集能量升级学技能（5 槽，Lv10 MAX）
- 击败精英怪掉落装备（6 槽），金币强化装备（Lv4 MAX），Lv2 时三选一锁定升级路线
- 擦弹 / 击杀充能，空格释放「万丝风暴」；P 暂停，M 静音
- 2:00 / 4:00 / 5:15 三场 BOSS 战，6:00 后黑潮暴走，难度指数上升
